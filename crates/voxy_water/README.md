# voxy_water

Библиотека генерации воды для Voxy. Одна и та же волна существует в двух видах:
на GPU (рендер) и на CPU (геймплей, физика). Поэтому предмет качается ровно на той
волне, которую видит игрок.

## Возможности

| Модуль | Что делает |
|---|---|
| `spectrum` | Направленные спектры: ветровое волнение JONSWAP с учётом длины разгона, распределение Donelan-Banner, зыбь, капиллярная дисперсия. Пресеты `ocean`, `storm`, `lake`, `pond`, `pool`. Начальные амплитуды Тессендорфа `h0(k)` считаются детерминированно на CPU по формулам оригинального шейдера. |
| `query` | `WaveField`: высота, нормаль и орбитальная скорость в любой точке и в любой момент времени. Строится из самых энергичных компонент той же таблицы `h0`, без чтения данных с GPU. |
| `bodies` | Типы водоёмов: `Basin` (бассейн или резервуар), `Region` (озеро или море по контуру; берег образует рельеф), `River`. `WaterWorld::sample` отвечает, есть ли вода в точке, на какой высоте поверхность и как вода движется. |
| `river` | Реки по сплайну. Скорость течения зависит от уклона русла, на крутых участках появляются пороги, на обрывах — водопады; под водопадом бурлит пена. |
| `shore` | Глубина и знаковое расстояние до уреза воды по карте рельефа. Волны гасятся на мелководье, а прибой обрушивается на берег (закон Грина, предел H ≤ 0,78·d). Тот же расчёт есть в WGSL, так что CPU и рендер совпадают. |
| `buoyancy` | Сила Архимеда, сопротивление относительно течения и волн, момент сил: тела переворачиваются и выравниваются. |
| `gpu` | FFT-поле волн (6 каскадов 256²) и интерактивная рябь: волновое уравнение на окне вокруг камеры с тороидальной адресацией, отражение от стенок бассейна. Использует только compute из базового профиля WebGPU, поэтому работает на desktop и в браузере. |
| `mesh` | Сетки поверхностей для всех типов водоёмов в едином формате вершины `WaterVertex` (с течением, пеной и признаком водопада). |
| `WATER_COMMON_WGSL` | Функции для шейдеров: `shore_wave`, `flow_phases` (двухфазная адвекция течением), `foam_pattern`. |

## Пример

```rust
use voxy_water::*;
use glam::{Vec2, Vec3};

let bathymetry = Bathymetry::from_fn(Vec2::new(-100., -100.), 1.0, [200, 200], |p| p.x * 0.05 - 2.0);
let world = WaterWorld::new(
    vec![
        WaterBody::sea(vec![/* контур */], 0.0, -10.0, ShoreField::new(&bathymetry, 0.0)),
        WaterBody::river(River::new(vec![/* узлы */], 1.2)),
        WaterBody::pool(Vec3::new(-2., -1.5, 0.), Vec3::new(2., 0.1, 10.)),
    ],
    WaveSpectrum::ocean(),
);
// геймплей и физика
if let Some(water) = world.sample(position, time) {
    let forces = buoyancy(&world, &Floater::cuboid(size, 3), position, rotation, velocity, spin, time);
}
// рендер: ArchiveSceneRenderer::set_water(&world), advance_water(dt), water_splash/water_wake
```

Витрина: `cargo run -p voxy_render --example water_showcase -- --shot out.png --view beach|falls|crates`.
Бассейн у виллы в `street_walk` использует ту же библиотеку: персонаж, идущий по воде,
оставляет за собой рябь, а при прыжке в воду поднимает всплеск.

## Ограничения

- Рябь сделана на волновом уравнении и видна только визуально. CPU-запросы её не
  учитывают, ширина окна — 24 м.
- Мокрый песок на берегу не затемняется: шейдер рельефа о воде пока ничего не знает.
- Водопад рисуется как лист со струями и пеной у подножия. Частиц брызг и тумана нет.
- Шейдеры волн и спектр взяты из web-ocean (Maksymilian Dendura, MIT), см. `LICENSE-web-ocean`.
