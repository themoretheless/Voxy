# Oriented character collision before root rotation

CharacterPhysics now accepts a unit-scale character owner with authored rotation. Ancestors remain translation-only and dynamic character ancestors remain unsupported. The runtime caches the owner's world-space half-edge vectors beside its velocity/grounding state. CharacterState.body exposes the enclosing anchored AABB; narrow-phase contact, overlap/recovery and explicit root displacement use the oriented shape, not that envelope. An authored orientation change follows the existing teleport/reset policy and resets velocity/grounding before the next accepted tick.

Continuous SAT uses three face normals for each box and nine edge-cross-edge directions. Edge directions are normalized before crossing, preserving separating axes when dimensions are tiny or large. Every nonzero separating direction is retained. The body orientation is fixed during the swept translation. Contact normals slide both requested motion and carried velocity; ground snap and jump suppression keep the existing controller policy. The axis-aligned body/world path still uses the prior swept AABB solver. Physics publishes scene transforms, runtime states and consumed input only after the complete staged tick succeeds.

Evidence in `artifacts/rig-oriented-character-2026-10-03` covers analytic tilted-face time of impact and scale invariance, an empty corner of the enclosing AABB, unequal body half-extents moving to a wall, tangential sliding, rotated floor support, jump velocity through a motion request, atomic initial-overlap rejection and opt-in recovery. Ordinary editor inspector rotation is accepted with undo/redo; nonunit scales are rejected without history changes.

The native diagnostic uses yaw 0.4, character half-extents (0.08, 0.05, 0.02), a wide explicit wall and the existing imported root-motion fixture. The root request is converted through the actor's rotated world basis. Presented Play verifies the exact wall-support position x=0.018526763, an in-place palette, preserved actor orientation and shared GPU resources; Stop restores authoring and releases animated resources. The collider is an authored diagnostic box, not a fit certificate for the model's full geometry.

Root rotation is not yet extracted/applied. Angular continuous collision detection and pose/physics feedback are required before adding rotating motion requests: endpoint-only orientation changes could cross an obstacle. Nonunit character scale, rotated/scaled scene ancestors, character-character collision, moving platforms and full dynamic rigid bodies remain open. This is not a CUDA or other-platform hardware certificate.
