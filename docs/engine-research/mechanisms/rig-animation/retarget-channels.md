# Explicit local-channel retarget binding

`voxy_animation::RetargetBinding` compiles a one-to-one named joint mapping between immutable source and target skeleton layouts. The mapping is bounded by `MAX_JOINTS` (256) and stores indices rather than searching names during playback. Missing names, repeated source or target ownership, nonunit basis quaternions and invalid translation scales reject compilation.

Each binding explicitly authors two axis corrections: rotation basis conjugates the animated rotation relative to source bind rotation; translation basis converts parent-local translation deltas and extracted root displacement. Translation scale is separately authored, including zero to suppress that channel. Target bind translation, rotation and signed scale remain the reference. Relative source scale channels multiply the target bind scale. Unmapped target joints retain bind pose.

This transports local animation channels. It does not infer semantic bone roles, solve world-space end-effector goals, compensate arbitrary differing hierarchies or infer character height/stride scale. Axis corrections must describe the appropriate source and target local coordinate frames. These limits are part of the API contract rather than hidden heuristics.

`apply_pose` returns a target-bound pose after target skin-palette admission. `apply_frame` transfers pose, selected motion joint, extracted displacement and blend weight in one candidate; it requires a mapped selected motion joint and rebuilds the palette for the target rig. It never extracts motion from a difference between bind translations, mutates either skeleton or publishes owner state. Derived output is validated before the caller can accept it.

CPU acceptance samples a source clip with different names, bind rotations, proportions, signed/nonuniform scale and joint ordering from the target. Independent formulas verify target translation, rotation, scale, root displacement, mapped joint index and target palette. Additional checks cover exact reconstructed source bindings, preserved target bind pose, unrelated target joints, malformed mappings and foreign/invalid source poses.

Editor source-asset selection, persisted retarget profiles, owner playback integration, physics/foot placement and native GPU acceptance for retargeted rigs remain required. Reuse the existing owner Animator and transactional fixed-tick preparation; do not create a second animation clock or parallel renderer. A target model supplies skeleton/inverse-bind/geometry, while an explicitly selected source supplies animation channels. Retarget before target-space root-motion consumption and target foot IK, then publish one accepted target palette through the existing GPU path. Ordered angular root paths need their own coordinate transport and collision proof.

Final checks: 72 animation CPU tests passed, including overflow recovery, and the editor dependency check completed successfully. Evidence: `artifacts/rig-retarget-channels-2026-10-03/`. No editor Play or native GPU retarget gate is claimed by this checkpoint.

## Ordered rigid-path coordinate transport (2026-10-04)

RootRigidPath::transformed changes coordinates by x_target = scale * basis * x_source + offset. The resulting rigid action has rotation basis * R * inverse(basis) and translation scale * basis * t + offset - R_target * offset. Each span retains its authored quaternion shape, time range and STEP event; conjugation changes left/right quaternion factors rather than flattening cubic curves. Both additive and pivot Bernstein coefficients are transformed, so projection hull and point-speed proofs remain attached to the actual path. Span count/duration and rotation winding bounds remain unchanged. The operation admits finite unit bases, nonnegative finite scales and finite offsets and rejects arithmetic overflow without changing the original path.

All 73 animation CPU tests passed. The new regression checks LINEAR/STEP/CUBICSPLINE paths crossing multiple loops, independent transform formulas at 101 fractions of every span, preserved span ordering/event boundaries, projection enclosure, derivative speed bounds, zero and positive scale, invalid parameters and successful recovery after overflow rejection. Evidence: `artifacts/rig-root-coordinate-transport-2026-10-04/`. Profile-derived conversion, differing rotation/translation basis admission, masked axes, target ancestor conversion, character collision acceptance and native angular retarget remain required; the editor still explicitly rejects angular retargeting until these are connected and verified.
