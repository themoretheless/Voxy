# Implementation checkpoint: transactional L-BFGS equilibrium

The public `Body::equilibrate_lbfgs` now runs on a trial body and commits positions only when the free-node force residual meets the requested tolerance. Iteration exhaustion or line-search stagnation with a larger residual returns an error and leaves the accepted state unchanged. The diagnostic observed/state APIs retain final-iterate access and their documentation distinguishes this behavior.

XPBD edge/tetrahedron multipliers already accumulate within each step in `tissue.rs`, with compliance scaled by dt²; no duplicate implementation was added. The anatomical viscoelastic step already rejects nonconvergence before committing material memory. The existing contact implementation still needs a separate normal-reaction audit; this checkpoint does not claim to change friction.

Regression reproduces an exhausted one-iteration solve with finite, changed diagnostic geometry and an above-tolerance force residual, verifies strict rollback including reference and evaluated loads, then verifies convergence gives exactly the same geometry as the diagnostic solve.

Validation: `cargo test -p physics --test tissues`: 11 passed. `cargo test -p physics --test lbfgs`: 8 passed; the same 8 tests passed in release, including the contact load/release cycle.

## Contact friction from projection reaction

`Tissue::step_with_contact` now accumulates each particle/sphere and triangle/sphere normal projection multiplier within a step. Friction uses the resulting normal impulse lambda/dt, with inverse/effective mass converting impulse to a tangential velocity correction. The cap is mu*normal impulse and also stops at zero tangential velocity. Multipliers reset each physical step. Previously the cap depended only on predicted incoming normal speed, missing pressure generated by elastic constraints.

Measured regression with one movable particle pressed against a fixed sphere by a shortened elastic link, tangential initial velocity 1 m/s, no incoming normal velocity, dt=0.001 s, 64 iterations: no-friction tangential speed 0.952027601 m/s; mu=0.5 gives 0.452003398 m/s. The fixture checks fixed support and nonpenetration. A separate isolated-contact regression checks the impulse budget over three dt values, three inverse masses and two iteration counts, including no reversal.

Scope: this remains a discrete XPBD projection approximation. Summed positive corrections are not a globally converged contact complementarity solution. Contact directions/features may change over iterations; swept collision and calibrated wet-tissue friction are not established. This module does not change the anatomical HGO solver or face renderer.
