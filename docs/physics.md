# physics

Целевое назначение — переиспользуемая библиотека физики для разных движков. Текущая реализация пока использует `voxy_world` и `voxy_core`; универсальность API не завершена. Следующий архитектурный этап — независимые математические типы и интерфейс запросов к окружению, а воксельные лучи, коллизии, воду и разрушение вынести в адаптер. Переименование не меняет поведение расчётов.

Физика выделена из `voxy_world` и `voxy_runtime` в отдельный crate.

Зависимости: `physics → voxy_world → voxy_core`, а также прямое использование `voxy_core`. Модуль не зависит от окна, GPU, runtime и хранения на диске.

- `collision`: swept AABB, контакты и ограничение числа проверяемых вокселей.
- `raycast`: лучи по воксельной сетке и типизированные результаты попаданий.
- `character`: гравитация, прыжки, скольжение и подъём на ступени.
- `vehicle`: движение транспорта; существующие типы трассы пока перенесены вместе с ним.
- `projectile`: баллистика и обнаружение попаданий.
- `water`: планирование перемещения воды с сохранением объёма.
- `destruction`: планирование разрушений от взрывов.

Все публичные типы и функции экспортируются из корня `physics`. Потребители должны импортировать их оттуда; обратные re-export из мира отсутствуют, чтобы не создавать циклическую зависимость.

Мир сохраняет каноническое состояние блоков, описание `CollisionShape`, registry и транзакции. Физика читает `VoxelView`; вода и разрушения возвращают планы транзакций. Применяет транзакции владелец мира. Приложение задаёт ввод и фиксированный шаг, преобразует координаты для камеры и вызывает физику.

Проверка: `cargo test --workspace` и `cargo clippy --workspace --all-targets -- -D warnings`.
