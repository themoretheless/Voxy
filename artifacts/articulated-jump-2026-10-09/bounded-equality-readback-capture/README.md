# Bounded GPU equality staging

Independent equality owners now advance in ordered chunks that fit the device readback pool's currently available byte and buffer capacity. Cached buffers are evictable; active and quarantined buffers remain charged. A task that cannot fit alone is rejected before its resident QR state is encoded. Equations, physical tolerances, active-set decisions and publication gates are unchanged.

Validated: four readback pool tests; real GPU 65-owner stress twice for separate byte/count limits, each exact against scalar output, 33 submissions and zero quarantine; four-guide/four-step contact positions and velocities exact against serial; seeded negative-reaction release and dependent-hint cold retry; captured original 61-row/2646-coordinate physical contact fixture including cooperative comparison.

This does not qualify full 720-frame model dynamics, rendered >160 FPS, CUDA or all hardware. Existing long runs retain their older binary. The older cooperative full run terminated at frame 6 with 9.198537074470159e-6 m position drift and 1.9552032001785014e-4 quaternion-component drift; its original admission thresholds remain unchanged. The newer original-column velocity run was live at observation and has reported ReadbackBudget fallback; neither frozen run tests this patch.
