# Frame-scoped original contact capture

`physics::hair::observe_contact_frame(frame, closure)` labels diagnostic snapshots using a thread-local scope. Nested calls and panic unwinding restore the caller label; unrelated threads do not inherit it. Native island workers explicitly inherit the scope and restore their own previous label. This does not add process-global mutable frame state or change physics.

With opt-in island export, `VOXY_HAIR_ISLAND_INPUT_FRAME=4` selects only frame 4. Filtering occurs before native/external observation counters increment, so earlier frames cannot exhaust the capture budget. v2 metadata adds frame (integer or null for unlabelled calls); missing context does not falsely match a selected frame. Observation index still is not a physical substep/iteration or row identity. Physical quantity remains unspecified.

The full-model qualification wraps both native and external advance calls in the scope. Selected 300-island qualification passes unchanged physical gates and bitwise identical serial/2-worker/4-worker states and reactions. Nested panic/thread-isolation and nine original Newton/island tests pass. Actual Metal qualification passes with exact serial pose/rotation and zero native fallback; the frame-labelled GPU test writes 10 complete operators, all labelled frame 4 and all with exact independently reconstructed raw loads.
