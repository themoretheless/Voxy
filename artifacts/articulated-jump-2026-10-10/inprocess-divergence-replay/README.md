# Opt-in in-process divergence replay

The full-model GPU qualification fixture can retain both native and external mutable pre-frame states with VOXY_HAIR_DIVERGENCE_REPLAY_DIRECTORY=/absolute/fresh/directory. On the unchanged position/quaternion gate failure, it replays the same failing frame on all guides, traces the worst-position guide, exports separate phase/projection logs and a report, restores the original failed end states, and still fails the original gate. Default runs do not allocate these snapshots or replay. Groom/rest/render ownership stays with each original FemaleHair. GPU workspaces are reused rather than checkpointed; bitwise endpoint pose comparison is explicitly reported, never assumed. A quaternion-only failure traces the guide with the largest quaternion component error; a position failure traces the guide with the largest position component error.

The CPU checkpoint test initialized the real 469-guide groom, selected four guides for bounded checkpoint mechanics, advanced two steps with collider refits, restored the complete mutable debug state (including solver/cache fields and collider), then repeated the next step with an identical full mutable-state fingerprint. Mesh/self contacts were disabled for this bounded checkpoint test. It does not qualify full-model collision physics, GPU replay or full trajectory. The full-model failure replay branch compiles but has not yet executed on a real failure.
