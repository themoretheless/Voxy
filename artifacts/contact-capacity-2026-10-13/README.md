The native preparation guard, GPU input codec, and three resident shader variants now retain up to 1024 original contact rows per connected island. Over-capacity inputs still fail before earlier accelerator work is submitted; no physical owner is split and no contact is removed. Physical tolerances remain unchanged.

The 1024-lane shader needs more than the default 16 KiB shared storage. Shader selection checks enabled storage limits, and the application qualification descriptor explicitly requests 16640 bytes for 1024 lanes. The 64-lane variant remains available under ordinary 16 KiB limits.
